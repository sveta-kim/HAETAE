## 최초 버전

2026-09-20, Windows / Node.js 24.10.0 환경에서 확인했습니다.

- `npm.cmd run check`: 전체 JavaScript 구문 검사 통과.
- `npm.cmd test`: 34개 테스트 통과, 실패 0개.
- 실제 이동·공격·술법·상호작용 입력으로 네 구역을 통과하는 시뮬레이션을 화이트·그레이·블랙 세 경로에서 각각 완료했습니다. 이 통합 테스트는 체력, 좌표, 보스 상태를 직접 변경하지 않습니다.
- 양심 75 경계, 인챈트 종료 후 30초 냉각, 보스 특수 기믹, 부적을 놓친 경우 회수, 체크포인트 검증과 재도전을 검사했습니다.
- Codex 내장 브라우저에서 시작, 이어하기, 부적 선택, 점프, 술법, 인챈트, Esc 일시 정지와 재개, 안내 모달을 확인했습니다.
- 390×844 및 1920×1080 뷰포트에서 가로 넘침 없이 표시되는 것을 확인했습니다. 전체 화면의 부적 선택·터치 인챈트·종료를 확인했습니다.
- 브라우저 검사 중 콘솔 오류·경고가 없었습니다.
- 로컬 정적 서버의 HTML/JS/SVG 응답이 정상이고, `.git`과 기획 문서는 웹으로 노출되지 않는 것을 확인했습니다.

브라우저 직접 조작 검사는 초반 플레이와 UI를 대상으로 했습니다. 캠페인 전체 완주와 세 엔딩은 게임 시뮬레이션의 자동 테스트로 확인했습니다. 실제 휴대기기·여러 브라우저·장시간 플레이 성능 검증은 아직 수행하지 않았습니다.
