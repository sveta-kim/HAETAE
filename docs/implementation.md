# HAETAE v0.1 구현 범위

이 버전은 전투와 진행을 실제로 조작하며 평가할 수 있는 캠페인 프로토타입입니다. 상용 출시용 전체 콘텐츠·아트 제작 완료를 의미하지 않습니다. 이 문서는 공개된 구현 범위를 설명하며, 비공개 기획서 원본은 저장소에 포함하지 않습니다.

## 채택한 기준

- 엔진은 기획서에서 미정이므로 웹 표준 Canvas 2D와 JavaScript ES 모듈을 선택했습니다. 로컬 실행과 피드백을 빠르게 반복할 수 있습니다.
- 주인공 표기는 설매화로 통일했습니다. 영문 본명 표기의 불일치는 새로운 인물을 추가하는 근거로 사용하지 않았습니다.
- 정화 후 75 이상은 화이트, 75 미만은 그레이라는 후반 최종 선택·분석 리포트의 조건을 적용했습니다. 별도의 관리자 잔류 선택지는 추가하지 않았습니다.
- 불가사리는 초반 현무가 없는 시점에 등장하므로 레벨 설명의 냉각 장치 기믹을 사용합니다.
- 파괴와 정화 모두 4구역의 탈출을 거칩니다. 서로 다른 추격자·색감·엔딩을 사용합니다.

## 축약한 부분과 후속 제작

현재 맵은 연결된 짧은 구역으로 구성됩니다. 장서각의 대규모 수직 미로, 다양한 진입 경로, 정교한 메트로배니아식 왕복 탐험은 추가 설계가 필요합니다. 기획서의 풍부한 환경과 보스 설정을 핵심 공략 중심으로 축약했습니다.

순라의 경보 증원, 전투 모션별 세밀한 애니메이션, 옷의 성장 단계별 변화, 궁극기 사용 시 위장 해제와 슬로 모션, 국본의 중력/스킬 봉인, 탈출의 중력 반전 및 회전 책장은 후속 구현 항목입니다. 현무의 슈퍼 아머는 별도 피격 넉백 시스템이 없는 현 전투에서는 차이가 제한적입니다.

설계자의 기록과 엔딩은 텍스트와 절차적 효과로 전달됩니다. 전용 일러스트·컷신·성우·정식 배경음악·마패 변신 장면은 제작하지 않았습니다. 캐릭터와 배경은 외부 에셋을 가져오지 않고 코드로 그립니다.

저장은 로컬 체크포인트 한 개입니다. 클라우드 저장, 사용자 계정, 게임패드, 리바인딩, 현지화, 설치형 배포, 장시간 성능/기기 호환 검증은 후속 범위입니다. 저장소의 소스 코드는 로컬에서 실행할 수 있으며, 운영 환경 배포는 제공하지 않습니다.

## 구조

게임 시뮬레이션은 DOM에 의존하지 않습니다. 고정 60Hz 갱신에서 입력을 소비하며 렌더링과 분리되어 있습니다. 레벨과 엔딩 데이터도 별도 모듈로 분리했습니다. 따라서 후속 아트 교체, 밸런스 변경, 저장 형식 버전 관리와 테스트 확장이 가능합니다.

술법 명령어는 게임 내부 식별자로만 사용하며 터미널이나 운영체제에 전달하지 않습니다. 외부 네트워크, 사용자 계정, API 키가 필요 없습니다.
