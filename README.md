# HAETAE — 금지된 성역

한국 설화와 디지털 세계를 결합한 **Godot 4 횡스크롤 액션 게임 프로토타입**입니다. 디지털 도사 설매화가 다섯 신수의 부적을 익히며 소도의 네 구역을 돌파합니다.

현재 개발 기준은 [`godot/`](godot/) 프로젝트입니다. 기존 JavaScript·Canvas 버전은 규칙과 조작을 비교할 수 있도록 저장소 루트에 남겨 두었습니다.

## 실행

Godot **4.7.2**에서 검증했습니다. Godot 프로젝트 관리자에서 `godot/project.godot`을 가져온 뒤 **실행(F6/F5)** 하세요. Godot 실행 파일이 PATH에 있다면 CLI에서도 바로 시작할 수 있습니다.

```bash
git clone https://github.com/sveta-kim/HAETAE.git
cd HAETAE
godot --path godot
```

Windows PowerShell에서 Godot 실행 파일을 직접 지정할 수도 있습니다.

```powershell
& "C:\path\to\Godot_v4.7.2-stable_win64.exe" --path godot
```

## 조작

| 행동 | 입력 |
| --- | --- |
| 이동 | A / D 또는 ← / → |
| 점프 · 2단 점프 | Space / W / ↑ |
| 마우스 방향으로 기본 탄 발사 | 좌클릭, 누르고 있으면 연사 |
| 자동 강화 후 강화 탄 발사 | 우클릭, 누르고 있으면 연사 |
| 대시 | Shift |
| 부적 직접 선택 | 1–5 |
| 보유 부적 순환 | 휠 위: 앞 번호 / 휠 아래: 뒷 번호 |
| 선택한 부적의 고유 기술 | Q |
| 공격 없이 강화만 준비 | E |
| 장치·시민·성문·출구 조사 | F |
| 조작 안내 | H |
| 일시 정지 | Esc / P |

휠은 미획득 부적을 건너뛰고 순환합니다. 좌클릭은 강화 중에도 기본 탄이며, **우클릭만 강화 효과를 사용**합니다. 탄은 벽·사물·처음 맞은 적에서 소멸하고 탐지는 벽 너머에도 적용됩니다.

| 부적 | Q 고유 기술 | E 강화 / 우클릭 효과 |
| --- | --- | --- |
| 주작 | 조준 화염탄 | 15초 화염 강화, 우클릭 피해 증가·화상 |
| 청룡 | 8초 탐지 | 12초 이동·대시·연사 강화 |
| 백호 | 12초 탐지, 각성 후 보안문 개방 | 은신·우클릭 치명타, 각성 후 30초 은신 |
| 현무 | 5초 방패·탄 반사 | 12초 피해 감소·반사·근접 반격 |
| 기린 | 국본 격파 후 루트 코어 조사 | 공격 강화 없음 |

강화가 끝나면 30초 냉각됩니다. 주작 Q는 문과 시민 기록도 파괴하므로 양심 수치에 영향을 줍니다. 능력 이름은 게임 속 표현이며 실제 운영체제 명령을 실행하지 않습니다.

## 플레이 범위

네 구역, 여섯 보스, 세 엔딩과 양심·기록·선택에 따른 진행을 구현했습니다. 부적 획득과 백호 각성 시 안전한 수련 공간으로 이동해 Q와 E의 차이를 직접 연습합니다. 수련을 마치거나 건너뛰면 원래 위치와 자원 상태로 돌아옵니다. 체크포인트는 Godot의 `user://haetae_checkpoint.json`에 저장되며 제목 화면의 **기록 이어하기**로 불러옵니다.

기존 웹판의 `localStorage` 저장은 Godot 저장 파일로 자동 이전되지 않습니다. Godot판을 처음 실행하면 새 게임으로 시작하세요.

## 개발 및 검증

Godot 코드는 [`godot/scripts/main.gd`](godot/scripts/main.gd), 레벨·부적·튜토리얼 데이터는 [`godot/data/game.json`](godot/data/game.json), 시작 씬은 [`godot/scenes/main.tscn`](godot/scenes/main.tscn)에 있습니다. 비공개 기획서 원본은 저장소에서 제외합니다.

Godot 스모크 테스트는 수련, 휠 선택, 발사체 충돌, 네 구역 진행, 엔딩, 저장 복원을 확인합니다.

```bash
godot --headless --path godot --script res://tests/smoke.gd
```

기존 웹판은 `npm run dev`로 실행하고 `npm run check`, `npm test`로 검증할 수 있습니다. 웹판은 참조 구현으로 보관하며 새 기능은 Godot 프로젝트를 기준으로 개발합니다.

전용 아트·컷신·정식 음악, 게임패드 및 키 재설정은 아직 작업 전입니다. 현재 화면과 효과음은 Godot에서 코드로 생성합니다.
