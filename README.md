# HAETAE — 금지된 성역

한국 설화와 디지털 세계를 결합한 **2D 횡스크롤 액션 게임 프로토타입**입니다. 디지털 도사 설매화가 다섯 신수의 부적을 사용해 소도의 네 구역을 탐험합니다.

현재 버전은 **JavaScript + Canvas 2D로 만든 웹 프로토타입**입니다. Godot 프로젝트는 아닙니다. 이동·전투·부적·튜토리얼·엔딩까지 플레이하며 게임 규칙과 조작감을 확인할 수 있습니다.

## 주요 기능

- 네 구역으로 이어지는 캠페인, 여섯 보스, 세 가지 엔딩
- 마우스 조준, 좌클릭 기본 탄, 우클릭 강화 탄, 누르고 있기 연사
- 벽·사물·첫 적에 닿으면 소멸하는 탄과 벽 너머를 탐지하는 스캔
- 다섯 부적의 고유 기술, 지속 강화, 종료 후 30초 냉각
- 부적 획득·각성에 맞춘 여섯 실습과 건너뛰기·재연습
- 양심·기억·선택에 따른 진행과 브라우저 체크포인트 저장
- 코드로 그린 픽셀 아트, Web Audio 효과음, 반응형 화면과 터치 버튼

## 빠른 시작

**Node.js 22 이상**과 최신 데스크톱 브라우저가 필요합니다. 외부 패키지 설치나 API 키는 필요하지 않습니다.

```bash
git clone https://github.com/sveta-kim/HAETAE.git
cd HAETAE
npm run dev
```

[로컬 게임 열기](http://127.0.0.1:5173/)에서 **소도에 접속**을 누릅니다. 서버 종료는 터미널에서 `Ctrl+C`입니다. Windows PowerShell에서 실행 정책으로 npm이 차단되면 `npm.cmd run dev`를 사용하세요.

다른 포트가 필요하면 PowerShell에서 다음과 같이 실행합니다.

```powershell
$env:PORT = "5174"
npm.cmd run dev
```

서버는 `127.0.0.1`에만 바인딩됩니다. ES 모듈을 사용하므로 HTML 파일을 직접 열지 말고 개발 서버로 실행하세요.

## 조작

| 행동 | 입력 |
| --- | --- |
| 이동 | A / D 또는 ← / → |
| 점프 · 2단 점프 | Space / W / ↑ |
| 마우스 방향으로 기본 탄 발사 | 좌클릭 · 누르고 있으면 연사 |
| 자동 강화 후 강화 탄 발사 | 우클릭 · 누르고 있으면 연사 |
| 이동 방향으로 대시 | Shift |
| 부적 직접 선택 | 1–5 또는 부적 버튼 |
| 보유 부적 순환 선택 | 휠 위: 앞 번호 / 아래: 뒷 번호 |
| 선택한 부적의 고유 기술 | Q |
| 공격 없이 강화만 준비 | E |
| 시민·장치·성문·출구 조사 | F |
| 일시 정지 / 재개 | Esc / P |
| 작전 안내 | H |

휠은 **미획득 부적을 건너뛰고** 번호 순서대로 순환합니다. 1·2만 보유했다면 1에서 위로 돌릴 때 2가 선택됩니다. 다섯 부적을 모두 얻으면 1↔5가 이어집니다. 미획득 부적을 숫자키로 선택해도 고유 기술과 강화는 사용할 수 없습니다.

마우스 조준과 휠은 게임 화면 위에서 사용합니다. 창이나 탭을 벗어나면 일시 정지합니다. 터치 버튼도 제공하지만 현재 조작감 검증의 기준은 데스크톱 키보드와 마우스입니다.

## 부적과 강화

| 부적 | Q 고유 기술 | 강화 효과 |
| --- | --- | --- |
| 주작 | 조준 화염탄, 처음 맞은 대상에 52 피해 | 15초 동안 우클릭 피해 1.7배, 3초 화상 |
| 청룡 | 숨은 길과 환영 8초 탐지 | 12초 동안 이동·연사·대시 강화 |
| 백호 | 12초 탐지, 각성 후 가까운 보안문 개방 | 은신과 우클릭 치명타, 각성 후 지속 시간 증가 |
| 현무 | 5초 방패와 탄 반사 | 12초 동안 받는 피해 감소·반사·근접 반격 |
| 기린 | 조건을 충족한 루트 코어에서 사용 | 강화 없음 |

- 좌클릭은 강화 중에도 기본 탄입니다. 우클릭이 강화 효과를 사용합니다.
- E는 공격 없이 강화만 준비합니다. 강화 종료 후에는 30초 냉각이 적용됩니다.
- 다른 부적을 선택해도 이미 켠 강화는 유지됩니다. 유지 중인 강화의 부적을 선택해 우클릭하거나, 강화가 끝난 뒤 새 부적을 사용하세요.
- 주작 Q는 기력을 소모하며 문과 시민 기록을 파괴할 수 있습니다. 일반 적 처치는 양심을 낮추지 않습니다.
- 명령어 형태의 능력 이름은 게임 속 표현이며, 실제 운영체제 명령을 실행하지 않습니다.

## 튜토리얼과 저장

처음에는 **좌클릭 → 조준 Q → E 준비 → 우클릭 강화 탄**을 표적에 사용하며 차이를 배웁니다. 이후 부적 획득·각성 시 탐지, 반사, 은신, 권한 개방을 연습합니다. **선택한 부적 연습**으로 다시 배울 수 있습니다.

수련 중에는 실전 적·탄환·추격이 멈춥니다. 수련이 끝나면 시작 위치와 실전 자원 상태를 복원합니다. **나중에 배우기**로 건너뛰거나 완료 후 F로 모험을 재개하세요.

구역 전환·체크포인트·보스 격파·주요 선택에서 같은 브라우저의 `localStorage`에 저장합니다. **기록 이어하기**로 재개하며, 새 게임은 기존 체크포인트를 교체합니다. 브라우저·포트를 바꾸거나 사이트 데이터를 지우면 기존 기록을 사용할 수 없습니다.

## 개발 및 검증

```bash
npm run check
npm test
```

Node.js 내장 테스트 러너를 사용합니다. 현재 **65개 테스트**가 입력, 조준·충돌, 강화, 보스, 저장 복구, 여섯 수련, 네 구역 완주와 세 엔딩을 검증합니다. 구문 검사와 테스트에는 실행 중인 개발 서버가 필요하지 않습니다.

| 경로 | 역할 |
| --- | --- |
| `index.html` / `src/styles.css` | 게임 화면, HUD, 안내, 반응형 UI |
| `src/main.js` | 게임 루프, UI 연결, 브라우저 저장 |
| `src/game.js` / `src/content.js` | 전투·진행 규칙, 레벨·부적 데이터 |
| `src/input.js` / `src/collision.js` | 키보드·마우스·터치 입력, 탄 이동 경로의 충돌 |
| `src/tutorials.js` / `src/ability-info.js` | 부적 실습과 효과 설명 |
| `src/renderer.js` / `src/audio.js` | Canvas 렌더링과 Web Audio |
| `scripts/` | 로컬 서버와 구문 검사 |
| `tests/` | 자동화 테스트 |
| `docs/` | 구현 범위, 엔진 인터페이스, 검증 기록 |

자세한 내용은 [구현 범위](docs/implementation.md), [엔진 인터페이스](docs/engine-contract.md), [검증 기록](docs/verification.md)을 참고하세요.

## 현재 범위

정식 출시 버전이 아닌 플레이 가능한 프로토타입입니다. 전용 아트·컷신·정식 음악, 대규모 맵, 게임패드·키 재설정, 클라우드 저장은 제공하지 않습니다. 실제 모바일 기기와 여러 브라우저에서의 장시간 검증도 아직 수행하지 않았습니다.

비공개 기획서 원본과 로컬 설정, 환경 변수, 로그, 테스트 결과 및 빌드 산출물은 `.gitignore`로 제외합니다. 게임 실행에 필요한 소스·에셋·테스트와 사용 문서는 저장소에 포함합니다.
